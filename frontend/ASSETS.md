# Visual assets

All three artwork assets were created with the built-in image_gen tool for this implementation and optimized to WebP with Sharp. They are artist impressions, not telescope photographs, observed planetary surfaces, or scientific evidence. The generated originals remain in the image tool's output directory; project code only uses assets in `public/images`.

The supplied `Stellar Archive Exoplanet Dashboard(1).png`, recovered from the linked conversation attachment, was the primary composition/style reference. Icons, orbital paths, the wireframe planet, and the star-map preview are static SVG components.
